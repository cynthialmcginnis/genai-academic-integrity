# Stand Over Your Own Work

An interactive lecture on GenAI and academic integrity. A live Three.js model of the six fundamental values of academic integrity anchors 16 slides and four classroom activities.

## Use it

Open `index.html` in a browser, or visit the GitHub Pages site for this repository.

| Key | Action |
| --- | --- |
| ← → | Previous / next slide |
| N | Speaker notes |
| F | Full screen |
| T | Two-minute discussion timer |

Link straight to a slide with `#s` plus its number, for example `#s13` for the hallucination activity.

## What's inside

- A 3D model of honesty, trust, fairness, respect, responsibility and courage that turns to each value as you reach it
- **Spot the hallucination:** a GenAI answer with three planted errors, including a fabricated citation
- **Use or misuse?:** six scenarios for a class vote, each with a verdict and the value it tests
- **Acknowledgment builder:** the toolkit's statement template, filled in live
- A show-of-hands tally and speaker notes on every slide

Everything runs in one file. It needs an internet connection for Three.js (cdnjs) and Google Fonts.

## Source and attribution

Adapted from *Toolkit for the Ethical Use of Generative Artificial Intelligence in Learning & Teaching* (October 2023), produced by the University College Cork Skills Centre and the National Forum for the Enhancement of Teaching and Learning in Higher Education. The six values are the Fundamental Values of the International Center for Academic Integrity.
